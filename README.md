# ナレッジ・テクノロジーズ 企業サイト

株式会社ナレッジ・テクノロジーズのコーポレートサイトです。要件定義から設計・実装・運用保守までを一貫対応する受託ソフトウェア開発会社としての事業紹介、開発実績、開発プロセス、会社概要、お問い合わせ導線をまとめた1ページ構成のサイトです。

## 構成

- `index.html` — ページ本体（TOP / 事業内容 / 実績 / プロセス / 会社概要 / CONTACT の各セクション）
- `styles.css` — スタイルシート
- `script.js` — ナビゲーションの開閉やスクロール連動などの挙動

## ブラウザで開く手順

ビルドや依存パッケージのインストールは不要です。`index.html` をブラウザで開くだけで表示できます。

1. このリポジトリをクローンまたはダウンロードする
2. `index.html` をダブルクリックする、もしくはブラウザのウィンドウ / タブにドラッグ&ドロップする

コマンドラインから開く場合は、リポジトリのルートディレクトリで以下を実行してください。

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

### ローカルサーバー経由で開く場合（任意）

一部のブラウザ環境では `file://` での直接表示時にフォントの読み込み等で挙動が異なることがあります。その場合は簡易的なローカルサーバーを立てて確認してください。

```bash
python -m http.server 8000
```

起動後、ブラウザで `http://localhost:8000` にアクセスしてください。
